# UICLI

UICLI is a small command-line project created for the GitHub UI and Git CLI final project. It includes a Bash calculator that computes simple interest from a principal amount, an annual rate, and a time period.

## Simple Interest Calculator

Run the calculator with Bash:

```bash
bash simple-interest.sh
```

The calculator prompts for the principal, annual rate of interest (as a percentage), and time period (in years). It calculates simple interest using:

```text
simple interest = principal * rate * time / 100
```
